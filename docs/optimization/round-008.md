# 优化轮 008：memcpy 混合对齐 u32 字循环——跨奇偶拷贝 3.3x，内存原语三件套收官

- 日期：2026-10-18
- 轮次性质：自动化第 7 轮
- 类型：性能（内存原语热路径，round-001 遗留项收尾）

## 本轮目标

memcpy 宽通道的最后一块盲区：一端 ≡0、一端 ≡4 (mod 8) 的**混合对齐**形态
（源/目标 x 奇偶不同的行拷贝、窗口合成 src/dst 不同余）此前整段退化字节
循环。互相对齐不可能（余数不同），但双端只要 4 对齐即可用 u32 字循环。

## 改动点

| 文件 | 改动 |
| --- | --- |
| `kunxcore/src/main.rs` `memcpy` | 8 对齐分支后新增 `else if (d&3)==0 && (s&3)==0` 混合对齐分支：`lw/sw` 字循环（4 对齐地址天然合法），8B/迭代（2×lw+2×sw）+ 尾部单字 + 字节循环 |
| `shared/ttf_text.rs` `wide_copy` | 用户态同款分支（asm 写法对齐本文件既有风格） |
| `kunxcore/src/compositor.rs` | 新增 `bench_row_copy_cross(xs, xd, ...)`：canvas(x=xs)→back(x=xd) 跨奇偶行拷贝基线 |
| `kunxcore/src/anim.rs` | perftest 场景 D2：even→odd / odd→even 双向 + 同奇偶对照 |

语义：字循环按地址顺序搬移非重叠数据（memcpy 前提），与字节循环结果逐位
一致；lw/sw 只触及 4 对齐地址（真机安全，不依赖非对齐访问）。

## 验证

### 量化（perftest 场景 D2，git stash 对照）

| 内核 | even→odd | odd→even | 对照 D 同奇偶 |
| --- | --- | --- | --- |
| 修复前（字节循环） | 598µs | 596µs | 128µs |
| 修复后（u32 字循环） | **181µs** | **178µs** | 125µs |

**3.3x**；跨奇偶与同奇偶宽通道的差距从 4.7x 收窄到 1.44x（字循环为宽通道
一半吞吐，符合预期）。D（125/124µs）、E（64µs）、A/B/C 同场无回归。
