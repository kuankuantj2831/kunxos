## 统一假说（本轮最大产出：一个机制解释全部历史签名）

**/var/run（SFS 512 inode 实例）inode 耗尽**：
- 写者每条 open 失败（iter~29）→ `fail()` 退出 → **DONE 哨兵永不写** →
  r39/r56「dones=2 冻结」✓（2 个写者赶在耗尽前写完）
- 部分写者死亡 → 终局断言「丢失消息 seq=N」✓（r56 第二跑）
- 轻载快跑（写者 48 条全写完、读者认领少 → 文件少）→ 偶然 PASS ✓
  （r40 当日 6/6 = 全部轻载快跑；r57 隔离窗 8 文件常驻 → 耗尽更快 →
  3 败 1 过比 r40 更差 ✓ 一致）

**耗尽来源**：读者每轮认领 rename 管道→taken_k（新 inode），隔离删除
unlink(taken_{k-8}) 若未真正回收 inode（SFS unlink→inode_free 路径
存在于代码，但 rename+unlink 组合下的回收正确性未验），文件数单调
增长至 512。
