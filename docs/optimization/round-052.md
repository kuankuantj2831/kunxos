# 优化轮 052：连续风暴定证 40/40 全达——内核与 OOBE 双洗清，r49-51 悬案以产品无罪结案

- 日期：2026-10-20
- 轮次性质：自动化第 51 轮（r51 计数器读局）
- 类型：定证收官轮

## 实验（tools/tap_storm.py，新工具入库）

GUI 启动 25s 后对欢迎页「下一步」(465,925) **连续风暴 40 次**（60ms 按住 +
1.8s 间隔，与 r47 采集同参数）：

```
OOBE downs@465: 40/40    （100% 到达）
点击下一步: 39/40        （97.5% 成效——含卡片页一路推进到第 9/13 步）
input丢弃计数: 无输出（无任何环形丢弃）
```

## 判决（r49→r52 四轮悬案结案）

- **内核输入路径无罪**：风暴下零丢弃、全送达；
- **OOBE 点击处理无罪**：连续点击在卡片页同样推进（时区/模块/网络…）；
- **r47 的「52 发 8 达」是 boot_trace 窗口化点按的时序伪影**：点按仅发于
  步进检测后的 8s 窗（首拍落在入场动画期被 pump 吞 + 检测延迟吃窗），
  与产品无关。r49 的 UX 缺陷担忧、r50 的两级丢失定性中「一级」撤案，
  「二级」（动画期吞点击）维持已知设计特性。
