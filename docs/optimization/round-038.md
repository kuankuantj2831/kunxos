# 优化轮 038：dentry 失效双 bump 加固 + 第五分发点补 hook + mailbox 抖动归因

- 日期：2026-10-20
- 轮次性质：自动化第 37 轮（r37 失败档案的纪律性跟进）
- 类型：存储正确性加固 + 归因实验

## 机理定证与加固（fsops.rs 五分发点）

1. **r36 单入口 bump 的理论时序窗**：bump→实际目录写之间，并发 miss
   回填可缓存到变更前状态。修法：**入口+出口双 bump**（窗口内任何回填
   被出口 bump 立即失效；严格更安全，零成本）。
2. **第五分发点漏网**：`fs_symlink`（创建 symlink 目录项）r36 未 hook——
   补双 bump。目录变更分发点全集最终为五：create/mkdir/symlink/unlink/
   rename（truncate/write 不动目录项）。

## 归因实验（本轮主交付）

| 内核状态 | sfsrace 专用门 | 结论 |
| --- | --- | --- |
| r36（单 bump） | 3/3 PASS（累计 6/6） | 无失败证据 |
| r38（双 bump+symlink hook） | **4/5 PASS**（1 败） | 与 r36 无显著差异（p≈0.4） |
| r37（类型线程，已回滚） | 1/3 PASS | 明确关联（失败率远超噪声） |

**失败签名再定性**：`超限时 dones=2`——「超限时」= 截止期形态（2 条
done 尚未认领时超时），非「丢失」形态。结合历史档案（mailbox 假失败
KOS 工单期修过一次：认领退出逻辑不可达 + 判定门），指向 **mailbox
截止期在 TCG 负载下的抖动**这一独立老病，与 dcache 正确性无证据关联
（r36/r38 合计 10/11 PASS，唯一失败是超时签名）。
