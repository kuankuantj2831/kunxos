# 优化轮 012：帧率上限拉满——内核精确睡眠解锁 + 240Hz 帧时钟 + 呼吸动画真实时间化/抗锯齿 + 渲染热路径三优化

- 日期：2026-10-18
- 轮次性质：用户直接指令轮（「把帧率上限/流畅度/画质提到极限」）
- 类型：系统级帧率上限移除 + 动画画质（与自动化轮 009/010/011 并发，文件归属见下）

## 本轮目标

移除全系统帧率的**人为上限**，把动画流畅度与画质推到当前渲染管线的物理极限。

## 改动总览

### 1. 内核：nanosleep 微秒精度（全系统解锁，根因修复）

`sched_cfs.rs::sleep_until` 登记睡眠者后**立即把硬件定时器重编程**到
「时间片剩余 vs 最近睡眠截止」的较早者（`timer::timer_set_interval(
next_timer_interval_us())`，中断已屏蔽、program() 取 ch1/ch2 较早者）。

此前只登记不重编程：硬件仍指向旧到期点（最远 10ms 外），唤醒只能等下
一次定时器中断兑现 → **nanosleep 实际精度被量化到 10ms，这是全系统
帧循环 ~100fps 上限的根源**（`tick()` 的提前唤醒路径与 `timer_rearm`
处理器本就就绪，缺的只是这一行补全）。

### 2. 内核：动画帧时钟常态 120→240Hz（power.rs + anim.rs）

`anim_frame_interval_us()` Normal/Warm 档 8333→4167µs；动画按真实时间
积分（dt/t 取 now_us），240Hz 只提高采样密度不改动画速度。热档 90Hz/
低电 60Hz 降档策略不变。perftest 判定与看门狗阈值同步更新
（240Hz 预算 4.17ms），docs/animations.md、docs/perf-baseline.md 同步。

### 3. OOBE：呼吸动画真实时间化 + 亚像素抗锯齿 + 变化检测

| 组件 | 此前 | 现在 |
| --- | --- | --- |
| dot 呼吸 | 24 帧计数 + 整数半径（24 帧中 23 帧同为 r=5，实际是每周期一帧的单点闪跳） | mono_us 三角波（400ms 周期）+ 4x4 超采样 AA 连续半径 5.0↔6.0，1/32 半径量化变化检测门控呈现 |
| hero 呼吸 | 40 帧计数 + 整数半径（0.975..1.025 缩放只剩 2~3 级半径跳变） | 真实时间（640ms 周期）+ **8x8 超采样 AA 圆盘**（64 级覆盖）+ 1/64 半径量化 |
| 按钮回弹 | 9 帧计数（帧率拉满后被压缩成闪跳） | mono_us 150ms 真实时长 |
| 空闲帧距 | sleep_ms(8)（实际 ~9.3ms，tick 量化） | sleep_us(2000)（实际 ~3.9ms，含 TCG 宿主侧定时器派发延迟 ~1.9ms） |

### 4. OOBE：渲染热路径三优化（hero 重绘 9.5ms→4.3ms，2.2x）

分段计时定位（每帧）：restore 1.3ms / draw 5.5ms / present 2.7ms。

| 优化 | 做法 | 收益 |
| --- | --- | --- |
| glow 缓存 | 光晕只依赖 (glow_r,a)，呼吸期绝大多数帧不变——缓存「快照+光晕」合成结果，命中整块行拷贝，跳过 9.4k 像素逐像素除法混合 | draw 5.5→2.2ms |
| present 行拷贝 | `present_back_rect` 逐像素 fb_set_px（每像素边界判断）→ 行 copy_nonoverlapping 直写显存 | present 2.7→1.45ms |
| restore 行拷贝 | hero 区域快照恢复逐像素循环 → `hero_restore_rows` 行拷贝 | restore 1.3→0.65ms |

`draw_brand_ex` 拆出 `render_hero_glow`（入场动画走 live 路径不变）。

### 5. launcher：动画预算 8→4ms + 转场纳入高刷 + 骨架屏提速

- `high_refresh` 增加 `MOTION.phase != Idle`（启动/返回/恢复/打断转场
  此前只吃 16ms 预算 ≈62fps）；高刷预算 8ms→**4ms（≈250fps 上限）**。
- 前台等待分支 sleep_ms(8)→sleep_us(4000)；骨架屏呼吸节流
  PLACE_FRAME_US 33ms→4ms（alpha 90 级/半周期 600ms，33ms 节流每帧
  跳 ~5 级肉眼可见台阶，4ms 后每帧 ~0.6 级连续平滑）。
- 新增 sleep_us 助手（与 OOBE 同款）。

### 6. （收编自自动化轮 011）转场隔行混合

`transition_pages` 混合路径改隔行（偶数行混合、奇数行 memcpy 复制上一
行，转场期垂直半分辨率）——自动化轮 011 实施并留在工作树，按其处置
说明由本轮一并带走。编译通过、GUI 0 PANIC；其量化因跨会话/宿主重启
不可归因（见 round-011.md），增益待后续轮同开机 A/B 复核。
